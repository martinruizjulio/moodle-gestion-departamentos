# AGENTS.md — Moodle Gestión de Departamentos

Este repositorio corresponde exclusivamente a **Moodle Gestión de Departamentos**. No confundir con la aplicación Moodle Windows, Congreso COIL u otros plugins Moodle.

Antes de cualquier tarea: leer `AGENTS.md`, `docs/CURRENT_STATE.md`, revisar código y commits recientes y detectar cambios de ChatGPT/Claude. GitHub es fuente de verdad.

El proyecto debe tratarse según su código Moodle actual. No reutilizar automáticamente scripts, plugins o configuraciones de otros Moodle del usuario.

Autorizado: auditar y modificar lo solicitado, crear archivos y ejecutar comprobaciones. Confirmar antes de migraciones destructivas, borrar datos, cambiar autenticación/roles/permisos, eliminar funcionalidades o sustituir arquitectura. Nunca guardar credenciales o tokens.

Tras cambios relevantes actualizar `docs/CURRENT_STATE.md` con cambios, validación y pendientes.
